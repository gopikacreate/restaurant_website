# Caffè Marlena

A single-page restaurant website built with plain HTML5 and CSS3.

## How to run

Open `index.html` in your browser.

## Files

- `index.html` - page structure and content
- `style.css` - all styling is present here

## Sections

- Header with navigation and a Reserve button
- Hero with the main "Book a table" button
- Menu (starters, mains, desserts)
- About
- Reservation form
- Footer with opening hours and location
